## E-Commerce Sales Dataset

This project contains an e-commerce sales database designed to analyze customer, product, order, and revenue-related data using SQL.

The database consists of several interconnected tables:

* **Customers:** Contains customer-related information such as customer ID, country, and signup date.
* **Orders:** Contains order details including order ID, customer ID, order date, and order status.
* **Order Items:** Contains product-level order information such as order ID, product ID, quantity, and price.
* **Products:** Contains product information including product name and category.
* **Sales Cleaned:** A consolidated table containing sales-related information such as order ID, product ID, quantity, price, revenue, customer ID, order date, status, year, and month.

### Data Analysis

The dataset is used to practice and demonstrate SQL concepts including:

* Data cleaning and missing-value checks
* Filtering using WHERE conditions
* Comparison and logical operators
* BETWEEN, IN, and LIKE operators
* Sorting and removing duplicates
* GROUP BY and HAVING clauses
* Aggregate functions such as SUM, AVG, COUNT, MAX, and MIN
* Window functions and PARTITION BY
* LAG and LEAD functions
* INNER, LEFT, RIGHT, and FULL OUTER JOINs
* Transactions using COMMIT and ROLLBACK

The project focuses on exploring e-commerce sales data, identifying data quality issues, analyzing revenue and order information, and understanding relationships between customers, products, and orders.

### Purpose

The main purpose of this project is to demonstrate practical SQL skills through an e-commerce dataset and build experience in data cleaning, data analysis, aggregation, window functions, joins, and transaction management.


## Udemy Finance and Accounting Course Analysis

This project contains a dataset of Udemy courses related to Finance and Accounting. The dataset includes information about courses, their ratings, reviews, subscribers, pricing, lectures, practice tests, and other course-related attributes.

### Dataset Overview

The dataset contains information such as:

* Course title and URL
* Number of subscribers
* Number of reviews and ratings
* Average rating and recent average rating
* Number of published lectures
* Number of practice tests
* Course price and discounted price
* Price currency
* Paid or free course status
* Wishlist-related information
* Course IDs and other attributes

### Data Cleaning and Analysis

SQL is used to clean, transform, and analyze the dataset. The project includes:

* Identifying and checking missing values
* Removing unnecessary spaces using TRIM
* Updating columns using CASE statements
* Filtering data using different operators
* Sorting and grouping records
* Applying aggregate functions such as SUM, AVG, COUNT, MAX, and MIN
* Using HAVING for grouped data filtering
* Working with DISTINCT and subqueries
* Using window functions such as ROW_NUMBER, RANK, LAG, and LEAD
* Creating SQL views for reusable analysis
* Creating indexes to improve query performance
* Using Common Table Expressions (CTEs) for complex queries

### Analysis Objective

The main objective of this project is to explore Udemy Finance and Accounting courses and understand patterns related to course popularity, ratings, reviews, subscribers, pricing, and course content.

This project demonstrates practical SQL skills in data cleaning, data transformation, exploratory data analysis, aggregation, subqueries, window functions, views, indexing, and CTEs.
